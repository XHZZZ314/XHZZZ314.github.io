ChoreoHelper 安装指南

FF14 国服编舞助手 v0.5.22 —— 时间轴编舞 · 游戏内实时播放 · 定格预览 · 宏生成

⚠️ 前提：网页（浏览器）和游戏必须在同一台电脑上 —— 网页通过 localhost:48794 与游戏内插件通信。如果浏览器提示"混合内容"被拦截，请允许访问 http://localhost。

方式一：插件仓库安装（推荐，更新自动）

  1. 启动橙月启动器（确认已启用 Dalamud）→ 进游戏
  2. 聊天框输入 /xlplugins 打开插件安装器；或按 Esc → Dalamud 插件设置
  3. 点设置/齿轮图标 → 自定义插件仓库（Custom Plugin Repositories） → + 添加（橙月版按钮名可能不同，请自行对照界面）
  4. 仓库 URL 填入：
    https://xhzzz314.github.io/choreo/repo/pluginmaster.json
  5. 保存后回到插件列表，搜索 ChoreoHelper → 安装 → 确保开关为启用
  6. 重启游戏（或重载插件）后，打开编舞网页：
    https://xhzzz314.github.io/choreo/

方式二：手动安装（离线，devPlugins）

  1. 下载 latest.zip（或解压分发包里的 repository/latest.zip）
  2. 先关闭游戏（避免 DLL 被占用），把 zip 里的 ChoreoHelper.dll 解压到：
    %AppData%\XIVLauncherCN\devPlugins\ChoreoHelper\
    （在文件资源管理器地址栏粘贴 %AppData%\XIVLauncherCN\devPlugins 回车即可；没有 ChoreoHelper 文件夹就新建，manifest.json 非必需）
  3. 启动游戏 → Dalamud 设置 → 确认已开启加载开发插件（DevPlugins）（若找不到可先跳过，多数版本默认扫描 devPlugins）
  4. 重启游戏后插件自动加载，打开上面的编舞网页即可

使用说明

功能操作
加动作左侧动作库点击动作，自动追加到时间轴
调整时间拖拽时间轴上的色块（可开 0.5s 吸附）
游戏内播放点 ▶ 按钮，角色按时间轴做动作
定格预览拖底部时间尺，角色定格在对应时刻的姿态
导出宏右侧宏面板复制，贴进游戏宏设置
歌词歌词按钮 → 网易云搜索 / 贴 LRC

连接状态看网页顶部：绿点 = 已连接游戏，灰点 = 游戏未开或插件未加载。先确认绿点再点播放。

⚠️ 风险须知

插件通过游戏自身的 ProcessChatBox 接口执行命令，与手动输入完全等价。但任何第三方插件都有理论上的风险，请在安全场合使用，自行斟酌。

常见问题

问题解决
网页显示未连接确认游戏已启动、插件已加载（聊天框有启动提示）。浏览器访问 http://localhost:48794/health 应返回 {"status":"ok"}
插件不加载/提示版本不兼容核对 Dalamud API Level 15、.NET 10 客户端；旧版本客户端需升级橙月启动器
端口 48794 被占用网页连不上时，命令行执行 netstat -ano | findstr 48794 查占用进程，关闭后重启游戏
角色不动游戏窗口别最小化；角色不能在战斗/过场中
动作被跳过/延迟上一个动作没做完会被打断，属正常；表情起手有前摇，可把动作整体提前 0.3-0.5s
排错看日志日志文件：%AppData%\XIVLauncherCN\dalamud.log，搜 ChoreoHelper 关键字
