ChoreoHelper 安装指南

FF14 国服编舞助手 —— 时间轴编舞 · 游戏内实时播放 · 宏生成

方式一：插件仓库安装（推荐）

  1. 打开橙月启动器 → 设置 → 插件设置 → 设置 → 添加自定义仓库
  2. 仓库 URL 填入：
    https://xhzzz314.github.io/choreo/repo/pluginmaster.json
  3. 插件列表搜索 ChoreoHelper → 安装
  4. 进游戏后，打开编舞网页：
    https://xhzzz314.github.io/choreo/

方式二：手动安装（devPlugins）

  1. 下载 latest.zip
  2. 关闭游戏，把 zip 里的 ChoreoHelper.dll 和 manifest.json 解压到 %AppData%XIVLauncherCNdevPluginsChoreoHelper
  3. 启动游戏，打开上面的编舞网页即可

使用说明

功能操作
加动作左侧动作库点击动作，自动追加到时间轴
调整时间拖拽时间轴上的色块（可开 0.5s 吸附）
游戏内播放点 ▶ 按钮，角色按时间轴做动作
定位拖底部时间尺，跳到该时刻并执行动作
导出宏右侧宏面板复制，贴进游戏宏设置
歌词歌词按钮 → 网易云搜索 / 贴 LRC

连接状态看网页顶部：绿点 = 已连接游戏，灰点 = 游戏未开或插件未加载。

⚠️ 风险须知

插件通过游戏自身的 ProcessChatBox 接口执行命令，与手动输入完全等价。但任何第三方插件都有理论上的风险，请在安全场合使用，自行斟酌。
